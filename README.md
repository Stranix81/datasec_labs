# Защита информации

## 📌 О проекте

Репозиторий включает все лабораторные и курсовую работы по курсу "*Защита информации*" (4 курс 1 семестр).
**Отдельный проект - отдельная лабораторная/курсовая работа**.

### 📎 Статус: обновляемый

## 📦 Лабораторные работы
### ♦ Лабораторная работа №1 (Простые симметричные методы шифрования)
 Цели:
  - Разработка программы, которая реализует шифрование и дешифрование сообщений, используя простые симметричные методы шифрования.
  - Реализовать два простых симметричных метода шифрования.

Задание:
  - Вариант 17 - **шифрующие таблицы Трисемуса** и  **шифр "скитала"**
    - Алфавит включает в себя 12 символов: цифры от 0 до 9, знаки "+" и "-".
   
### ♦ Лабораторная работа №2 (Шифры сложной замены)
 Цели:
  - Разработка программы, которая реализует шифрование и дешифрование сообщений, используя шифр сложной замены.
  - Реализовать один шифр сложной замены.

Задание:
  - Вариант 17 - **"двойной квадрат" Уитстона**
    - Алфавит включает в себя 35 символов: символы кириллицы, пробел и знаки препинания.
    - Размер каждой таблицы - 5x7.
    - Ключом является порядок букв, задаваемый датчиком случайных чисел.

### ♦ Лабораторная работа №3 (Криптоанализ)
 Цели:
  - Разработка программы, которая реализует шифрование сообщения, используя шифр простой или сложной замены.
  - Реализовать один шифр простой или сложной замены.
  - Реализовать алгоритм криптоанализа зашифрованного текста.

Задание:
  - Вариант 17 - **система Цезаря с ключевым словом**
    - Алфавит включает в себя 35 символов: символы кириллицы, пробел и точка.
    - Определить порядок первых 7 букв в ключевом слове (методом криптоанализа).

### ♦ Лабораторная работа №4 (Гаммирование)
 Цели:
  - Разработка программы, которая реализует шифрование и дешифрование сообщения, используя гаммирование.
  - Реализовать алгоритм гаммирования текста.

Задание:
  - Вариант 17 - **генератор Фибоначчи с лагами a=97, b=33** и **конгруэнтный генератор с модулем $2^{32}$**
    - Стартовые значения для генератора Фибоначчи генерируются конгруэнтным генератором.
    - Для преобразования целых последовательностей чисел в вещественные необходимо использовать деление на $10^{12}$ (на вход генератора Фибоначчи).
    - Для получения гаммы шифра числа последовательности фибоначчиева датчика необходимо умножать на $10^{12}$ и переводить в двоичную систему счисления.
    - Алфавит включает в себя 128 символов.

### ♦ Лабораторная работа №5 (Первый раунд алгоритма из курсовой работы)
 Цели:
  - Разработка программы, которая реализует шифрование и дешифрование сообщения, используя симметричный блочный алгоритм с обратной связью.
  - Реализовать полное логирование математических операций, происходящих на первом раунде алгоритма.

Задание:
  - Вариант 13 - **IDEA**
        
### ♦ Курсовая работа
 Тема:
  - Реализация режима обратной связи по шифртексту IDEA.

 Цели:
  - Разработка программы, которая реализует шифрование и дешифрование сообщения, используя симметричный блочный алгоритм с обратной связью.
  - Реализовать интерфейс для программы.

## 💻 Реализация
 - Каждый метод шифрования реализован в отдельном классе.
 - Сообщение реализовано в виде пользовательского класса Message.
 - Возможность загружать сообщение и ключи через текстовый файл.
 - Возможность выводить сообщение в текстовый файл
  

## 🛠️ Инструкции
### ♦ Клонирование репозитория
- Через графическую оболочку VS
  - На экране создания и выбора проекта нажмите "**Клонирование репозитория**" и вставьте ссылку на этот репозиторий

### ♦ Обновление репозитория
- Через графическую оболочку VS
  - В уже открытом проекте выберите вкладку "**Git**" и нажмите "**Получить**" или "**Синхронизировать**"

### ♦ Открытие файла-конструктора
1) Обновите Visual Studio до последней версии
2) Выберите проект с нужной лабораторной работой и либо дважды нажмите на .cs файл формы, либо нажмите **Shift + F7**
